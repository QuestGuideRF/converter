## Описание проекта

Конвертер файлов — это универсальный инструмент для преобразования файлов различных форматов. Приложение обладает простым и интуитивно понятным интерфейсом, который позволяет быстро и эффективно конвертировать файлы без необходимости в сложных настройках.

Основная цель проекта — создать удобное решение для обычных пользователей, которым требуется быстро преобразовать файлы из одного формата в другой.

### Целевая аудитория

- Обычные пользователи компьютеров, которым нужен простой инструмент для конвертации
- Офисные работники, работающие с различными типами документов
- Пользователи, которым нужно конвертировать мультимедиа файлы
- Любой, кто хочет избежать использования онлайн-сервисов конвертации из соображений приватности

## Функциональные возможности

- **Конвертация документов**: PDF, DOCX, DOC, TXT, RTF, ODT, HTML, MD
- **Конвертация изображений**: JPG, PNG, BMP, GIF, TIFF, ICO, WEBP
- **Конвертация видео**: MP4, AVI, MKV, MOV, WMV, FLV, WEBM
- **Конвертация аудио**: MP3, WAV, OGG, FLAC, AAC, M4A, WMA
- **Работа с архивами**: ZIP, RAR, 7Z, TAR, GZ, BZ2 (распаковка и создание)
- **Настройка параметров конвертации** для каждого типа файлов
- **Поддержка светлой и темной темы** интерфейса
- **Сохранение пользовательских настроек**
- **Пакетная обработка файлов** (до 10 файлов одновременно)
- **Единый интерфейс** для всех типов конвертации

## Технические требования

### Минимальные системные требования
- **ОС**: Windows 10/11, Linux (Ubuntu 18.04+), macOS 10.14+
- **Python**: 3.9 или выше
- **Оперативная память**: 500 мб
- **Место на диске**: 200 МБ + место для установки зависимостей
- **Процессор**: 2-ядерный процессор 1.5 ГГц или мощнее

## Категории конвертации

### 📄 Конвертер документов
- **Поддерживаемые форматы**: PDF, DOCX, DOC, TXT, RTF, ODT, HTML, MD
- **Возможности**:
  - Конвертация из PDF в DOCX, TXT
  - Конвертация из DOCX/DOC в PDF, TXT, HTML
  - Конвертация между форматами разметки (HTML, MD)
  - Сохранение форматирования при конвертации

### 🖼 Конвертер изображений
- **Поддерживаемые форматы**: JPG, PNG, BMP, GIF, TIFF, ICO, WEBP
- **Возможности**:
  - Настройка качества для JPG
  - Настройка прозрачности для PNG
  - Изменение размера изображения
  - Конвертация между любыми поддерживаемыми форматами

### 🎥 Конвертер видео
- **Поддерживаемые форматы**: MP4, AVI, MKV, MOV, WMV, FLV, WEBM
- **Возможности**:
  - Настройка разрешения видео
  - Настройка битрейта
  - Выбор кодека (при доступности)
  - Конвертация между различными форматами

### 🔊 Конвертер аудио
- **Поддерживаемые форматы**: MP3, WAV, OGG, FLAC, AAC, M4A, WMA
- **Возможности**:
  - Настройка битрейта аудио
  - Выбор между моно и стерео
  - Конвертация между различными форматами

### 📦 Работа с архивами
- **Поддерживаемые форматы**: ZIP, RAR, 7Z, TAR, GZ, BZ2
- **Возможности**:
  - Распаковка архивов
  - Создание архивов разных форматов
  - Просмотр содержимого архива
  - Выбор степени сжатия

## Работа с программой

### Основной рабочий процесс

1. Запустите приложение через `python main.py`
2. На главном экране выберите категорию файлов для конвертации
3. Добавьте файлы для конвертации (до 10 файлов)
4. Настройте параметры конвертации
5. Выберите формат, в который нужно преобразовать файлы
6. Укажите папку для сохранения результатов
7. Нажмите кнопку "Конвертировать"
8. После завершения процесса конвертации нажмите "Открыть папку" для просмотра результатов

### Пример конвертации изображения

1. Выберите категорию "Изображения"
2. Нажмите "Добавить файлы" и выберите изображения
3. В параметрах установите качество (для JPG) или выберите другие настройки
4. Выберите формат (например, PNG)
5. Укажите папку для сохранения
6. Нажмите "Конвертировать"
7. После завершения просмотрите результаты

## Настройка приложения

Для доступа к настройкам нажмите меню "Настройки" в верхней части приложения.

### Доступные настройки

- **Внешний вид**:
  - Выбор темы (светлая/темная)
  - Настройка размера окна (по умолчанию, полноэкранный или пользовательский)

- **Пути**:
  - Установка пути сохранения по умолчанию
  - Просмотр недавно использованных папок

### Сохранение настроек

Настройки автоматически сохраняются в файл `config/settings.json` и загружаются при запуске приложения.
